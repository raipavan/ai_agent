================================================================================
# 2. COMMON CAR ISSUES & SYMPTOMS
================================================================================

| Customer Complaint | Likely Cause | Recommended Service |
|-------------------|--------------|-------------------|
| Brake noise / squeaking | Worn brake pads | Brake pad replacement |
| AC not cooling | Low gas / dirty filter | AC gas top-up + cabin filter |
| Engine light on | Sensor / engine issue | Diagnostic scan |
| Car vibrating at speed | Wheel imbalance | Wheel balancing |
| Car pulling to one side | Misalignment | Wheel alignment |
| Strange engine noise | Belt / bearing issue | Belt inspection / bearing check |
| Water inside car | AC drain / door seal | AC drain check / seal inspection |
| Starting problem | Weak battery | Battery check / replacement |
| Clutch hard | Clutch plate wear | Clutch inspection |
| Gear shifting issue | Transmission fluid low | Fluid top-up / inspection |
| Suspension noise | Worn bushings / shocks | Suspension inspection |
| Battery dead | Old battery / no charge | Battery check / alternator check |
| Overheating | Low coolant / thermostat | Coolant check + thermostat |
| Smoke from exhaust | Oil burning / clutch | Engine diagnostic |
| Steering heavy | Power steering fluid | Fluid top-up / pump check |
| Unusual tyre wear | Alignment / suspension | Alignment + inspection |
